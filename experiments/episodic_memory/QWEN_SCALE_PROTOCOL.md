# 0.5B 与 1.5B 记忆实验：预先固定方案

目标：区分基础模型阅读能力与连续记忆接入损失。使用官方Qwen2.5-1.5B-Instruct，和此前Qwen2.5-0.5B-Instruct同系列对照。两者均已指令微调。冻结主干，不做LoRA；新模型的事件/问题特征、记忆模块和数据库全部重新计算。旧实验与权重保留。

数据及训练预算固定：复制此前seed7101的数据，包含32个训练owner×(16条已存+8条未存)以及原验证/测试集；两视图采样seed7102不变。记忆8×256，地址32维，分堆与磁盘算法不变。seed72重新初始化；字段CE+输入嵌入对齐+地址CE预训练2000步、batch32、lr0.001；随后固定写入与地址，仅训练读取投影、空记忆与位置向量1200步、有效batch16、lr0.0001，损失LM CE+字段CE+0.5×对齐，20%空记忆。1.5B隐藏维度不同，因此投影参数数量不同；此对照并非只改变单一参数量的严格因果实验。

先用独立3步小实验检查显存，丢弃其训练权重；正式训练重新初始化。若batch16超显存，使用小microbatch及梯度累积保持有效batch16，公开记录。固定选择最终1200步，不根据最终测试调参。特征缓存记录模型revision与维度，避免误用0.5B的隐藏状态。

拒答规则不变：地址证据>0.99，生成最小token条件概率>0.8且正常结束。所有生成保留原始输出与门控输出。数值相同不代表两个模型校准一致；尤其普通文本输入的自然措辞可能具有较低token概率。主能力比较同时呈现原始正确率，不单用拒答后分数推断模型能力。

测试分两部分：

1. **历史配对回归**：沿用此前60题真记忆/无记忆/同地址改事实/错误地址，以及12题只换问题、只换事件、同时改写、12题未存事件；旧模型使用原有结果，新模型完整重跑并检查独立进程重启和8题普通聊天前后输出。这里的失败问法已暴露，明确标为回归测试，不伪称盲测。
2. **新事件与固定新问法**：在正式训练结果出现前，生成seed8101的新测试事件（4个owner、每人32条已存+8条未存）；seed8102按每字段10题固定选择60题。新问法每字段两种，定义在新的比较脚本中，不参与训练。两个冻结最终模型都运行同样的问题及事实。

新集对照包含：直接提供正确事件文字（不检索，诊断性上限）；直接提供同样事实的清晰字段列表（控制文本格式）；正常磁盘向量记忆（部署路径）；强制正确事件ID的向量读取（oracle诊断）；无记忆。原问法与新问法分别计分，门控前后均记录。纯文字对照只用于评估，不作为正式记忆推理实现，不向正式ask接口提供原文或正确ID。

评分沿用目标字段唯一值匹配，保存逐题输出；对文字路径未通过严格匹配的情况进行人工抽样/审查，披露同义表达误判，不能据此直接把措辞变化算作语义能力差。所有结果只代表有限事实词表和地址空间；不宣称通用长期记忆、自动回忆或任意聊天无退化。
