# Qwen2.5-0.5B-Instruct 的连续事件记忆实验

目标：复用已有中文生成能力，训练事件编码/压缩与读取接入，并检验回答是否依赖磁盘中的经历。基座为官方Qwen/Qwen2.5-0.5B-Instruct，冻结全部494,032,768参数。原模型普通聊天路径显式绕过记忆模块，不能把这一点包装成“带记忆时任意聊天均不退化”。本轮不做LoRA，以隔离记忆模块本身的效果。

写入：基座对当前事件产生上下文隐藏状态；可训练投影与8个注意力池化查询压成8×256浮点向量。独立可训练地址头学习项目/第几次两个语义地址，共32维概率型地址。训练使用已声明的16×16地址监督；这不是开放世界自由寻址。SQLite只保存ID、owner、时间戳、FP16内容向量、FP32地址以及动态簇，没有历史文本、token ID或字段答案列。地址/簇常驻CPU，载荷按需从盘读取。

读取：问题经同一冻结基座提取特征，查询地址头预测地址；先搜2个动态簇、取最多4条载荷，证据不足最多全owner地址重试一次。按地址概率一致度选一条事件；连续记忆经可训练投影变成8个软token，直接参与冻结Qwen的前向生成，不先还原事件文本或用六分类答案替代模型输出。

训练：随机事实种子7101。32个训练owner，每人16条已存事件＋8条未存；验证4人×16条已存；测试4人×32条已存。训练事件原叙述和随机改写两视图；问题为原始与训练改写两视图。地址头先用训练集缓存特征学习2000步、batch64；随后冻结地址头，事件编码/接入模块用真实回答token的交叉熵训练1200步、batch4、学习率0.002。20%训练样本用空记忆，目标是“我没有这段经历的记忆”。基座只反向传递到输入软token，基座权重不更新。训练缓存和监督原文不向查询命令开放。

显存先做独立3步冒烟测试，后续主实验重新初始化所有可训练模块，只复用同一冻结基座的特征缓存。正式结果不包含冒烟模型。主实验用验证集观察，不根据最终测试改参数。若首版失败，仅在验证证据支持下记录后续修正；保留失败结果。

门槛：寻址证据>0.99；生成使用最小生成token条件概率>0.8且正常结束，才作为确定回答。0.8不再是旧57类softmax，数值不能当作跨架构校准一致性的证明，也不能据此声称实际错误风险更低。不调低任何门槛。报告同时给原始生成和最终拒答，不能把外部门槛的拒答当成模型学会了拒答。

固定最终测试：从未见过的测试owner选60个已存问题（每字段10题）和12个未存问题，问题带显式场景锚点；额外12个改写问题。四类条件：真实存储与正常检索；无记忆；同地址但事件六字段均改成不同值的反事实记忆；错误事件的地址与内容一起替换。反事实事实由不同随机种子生成，所有字段强制改变。错误的同地址记忆可能导致回答错误，但回答随记忆一致改变才是内容依赖的证据；模型没有外部真值，不能要求它识破任意伪造经历。

为了区分寻址和内容读取，另报告真实支持ID的诊断性读取上限，明确标为oracle，绝不用于部署路径或主成功率。普通聊天在训练前后对固定8题做贪心逐字对比，只证明冻结旁路保留基座行为，不证明基座回答都正确。独立查询进程只加载基座、适配器、SQLite和问题，重复重启验证落盘读取。

范围：有限词表事件、单条支持记忆、短回答；不是通用数字人或无限记忆。分簇只改变索引，不融合/删除载荷。报告保存全部问题、原始输出、拒答分数、错误条件实际注入值、模型来源revision和内存峰值。

## 验证驱动的公开修正（最终测试前）

初版 `qwen_memory_01` 的验证地址识别仅44/96正确；仅2.08%的支持问题通过0.99门槛。四个生成探针只有一条原始回答正确，四条最终均拒答。保留该失败checkpoint，不把训练损失下降当作读取成功。

第二候选 `qwen_memory_02` 新增8个有辅助监督的槽：人物、日期、事件、感受、原因、关注点、项目、次数。训练用8个字段交叉熵，及连续投影向量到冻结Qwen输入嵌入的归一化均方误差；短字段补“。”到4个位置，长度在训练端显式检查。字段标签、目标token和目标嵌入只供训练。部署时六个内容分类头不参与答案生成，不执行argmax查表；地址使用后两个头。查询地址改用两个可训练注意力池，从完整问题隐藏状态读取项目/次数。

8×256事件载荷仍落盘为FP16；读取时投影成32个连续软token，与固定“人物、时间、事件、感受、原因、关注、场景、次数”字段标记交错送进Qwen。固定标记不含任何事件值。该结构是有限字段的神经编码/解码器，并非开放语义的通用记忆压缩。数据库内容并不保密或不可逆，不能把“没有文本列”等同加密。

第二候选训练：seed72；先2000步batch32训练字段CE、嵌入对齐及查询地址CE，学习率0.001；再1200步batch4、学习率0.0003，联合优化LM CE + 字段CE + 0.5×嵌入对齐。预训练阶段验证字段和查询地址均100%正确，但联合优化后支持证据通过率从98.96%降至22.92%；读取探针也有字段混淆。因此再次修正，仍未查看最终测试输出。

最终候选 `qwen_memory_03` 从相同seed72重新开始相同2000步预训练；第二阶段固定事件编码器、所有辅助头与查询地址模块，只训练连续读取投影、空记忆向量和位置向量。1200步batch16、学习率0.0001，仍用同样损失与20%空记忆。正常聊天路径始终不更新。该修改直接阻止生成损失破坏已学好的地址/字段编码。训练阶段仍观察原定验证集，不挑选最终测试题，不降低门槛。

测试锁定最终1200步checkpoint，选择seed7301，错误记忆seed7302。60题主测试之外，另取每字段前2题组成12题固定配对集，分别只换问题、只换事件及同时改写。三个条件使用相同事件事实，改写调用训练未使用的heldout函数。不在测试后继续调参。

无记忆和地址不符条件最终答案受外部证据门控强制拒答，同时记录空记忆软前缀下的原始生成。错误地址不通过门槛时采用同一问题的确定性空记忆输出，等价于重跑相同输入。反事实记忆保留地址但改变六个事实，按注入事实和原真实事实分别计分。评分使用目标字段唯一值匹配，并保存完整生成供人工审查；并非人工评测或开放域语义判分。
