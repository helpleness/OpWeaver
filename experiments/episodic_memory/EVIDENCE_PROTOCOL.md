# 第三轮：证据与拒答实验（训练前固定）

以`paraphrase_structured`为冻结基座。模板3已用于诊断，之后的模板3成绩称为回归对比，不再声称全新句式测试。训练/验证仍排除模板2/3完整句式，不读取测试答案训练或选阈值。

## 诊断口径

对原句、只换问题、只换事件、两者都换做配对测试。对已存事件的UNKNOWN按顺序分类：

1. 正确事件未进入候选：检索漏失。
2. 正确事件进入候选，去掉UNKNOWN后最优答案正确：正确内容候选被拒答压过。
3. 第二项不满足，但只给正确事件后条件答案正确：候选干扰。
4. 只给正确事件后条件答案仍错：读取/编码/问题解释失败；再以真值任务槽探针辅助区分。

这些使用真值的干预仅用于分析，不用于正式推理。第二类不意味着可以安全取消拒答；无证据时强行选答案会猜测。

## 固定的改进与对照

- 旧模型：原分组路由。
- 旧模型+重试：第一次UNKNOWN才扫描当前owner全部地址，最多重新加载8条事件，最多两次读取。
- 混合库联合分类器：冻结编码器，原UNKNOWN与答案联合分类器继续训练。
- 混合库证据分离模型：相同冻结编码器、数据和步数；条件答案分类与逐候选证据验证分离。验证器接收学习地址的差与积、余弦、原有场景预测的概率一致性及内容幅度；没有字符串解析、真值场景或正确事件ID输入。验证分数同时影响读取注意力。

编码器和writer完全冻结，旧磁盘记忆无需重编码。训练使用原句库和两套增强事件表述库，问题使用训练增强；混合真实近邻、未知事件、移除支持事件、清空内容。两个新读出模型各3000步，batch16、AdamW 1e-4。只训练读取器和新增验证器，不挑选测试表现最好的checkpoint。

证据模型只有证据分数>0.99且条件答案置信度>0.8才作答。校准用验证owner的1800个无证据问题（未知、移除支持、空载荷各600），同时检查首轮与重试，证据门槛只可提高至覆盖验证负例；内容置信门槛固定。不会降低任一门槛来提高答对率。神经分数未经概率可靠性保证，必须报告独立测试的错误作答率。

## 评估

主比较沿用同一600问题、480已存和120未知问题；同时统计UNKNOWN、错误非UNKNOWN、最终召回、重试率。另做支持事件移除和空载荷测试，以及新随机事实/新owner的未知事件压力测试。排除的支持事件在重试中也必须保持不可见。

保留原模型、日志、阈值校准记录和全部失败。若提高回答率同时增加无证据乱答，不能宣称修复成功。小型合成任务和有限负例不提供真实对话无幻觉保证。

## 第一版失败后的探索性修正

完整保留`evidence_round_01`。首版证据模型在回归测试中过度拒答；补做600个正例验证，同样仅答对126个，而条件答案正确592个，472个被证据门槛拦住。负例校准全过不能代表可用，后续必须同时报告正例验证。

第二版`evidence_round_02`继续保持门槛0.99/0.8、所有编码器和训练样本不变。验证器删除高维地址坐标特征，仅保留余弦、两项学习场景概率一致性、内容RMS及峰值五项对称特征；同时加入正负两侧logit间隔损失`0.2*mean(relu(6-y*logit))`。这既要求真证据提高分数，也要求无证据降低分数，不使用全局温度放大或调低门槛。

第二版固定3000步，复用相同混合训练库；先做负例校准和600个正例验证，再测试。第一版测试已见，后续结果属于探索性修复对比。另使用新的随机事实种子90272检查新owner的未知事件，保留两版所有结果，不把重试当成预注册一次成功。

第二版正例验证0/600，条件答案592/600；因证据训练未达到固定门槛而不进入测试。第三版`evidence_round_03`保留其架构与门槛，按正负候选分别取均值后平均，平衡BCE和双侧间隔损失，避免大量负候选主导；仅验证器学习率改为1e-3，读取器仍1e-4。固定3000步后先验证，未以测试成绩选择checkpoint。这一修正同时改变了损失权重和优化速度，不能独立归因。
