# 残余拒答与错误回答：本轮方案

诊断旧回归集的45次拒答与13次错误回答，诊断使用真实事件/任务作干预，仅用于解释。旧结果可用于开发，不能当新的独立泛化证据。13次错误中11次问情绪答原因、2次日期错误，13次真实槽探针均正确。45次拒答的互斥诊断：31证据拒绝、4内容拒绝、6事件排序错误、1候选干扰、1槽可解但读取失败、2槽和读取同时失败。

固定修改：冻结写入器、旧查询地址编码器；新增独立意图编码器，显式计算 P(字段|问题) × Σ P(事件|查询)P(字段值|事件槽)。用字段概率分布传播不确定性，避免读取器将低置信度意图放大。训练潜在地址的残差语义分类器，改进事件匹配；仍使用证据>0.99和内容>0.8的双门槛，以及最多一次重试。校准只能升高证据门槛。

训练只用已有train事实、原始及两份训练改写库；新增训练问句在residual_language.TRAIN_STEMS中。固定种子44，3000步，batch32。学习率3e-4（验证器1e-4）；目标为有支持的答案CE+意图CE+0.5槽字段CE+0.3地址语义CE+平衡证据BCE+0.2双侧间隔损失。先做独立validation正负验证，之后才运行封存测试。

新事件种子90381、90382（各8个owner、每人96已存事件、8未存事件）；测试问题去重抽样480已存+120未存。新测试完整句式在residual_language.TEST_STEMS和fresh_event，不在训练生成器采样。保持现有词表，检查未知词和长度；新事件是已有16×16定位空间、有限答案词表内的新随机事实组合，不是开放世界实体泛化。

第一套新历史做原始、只改问题、只改事件、同时改写四条件，第二套用另一种新叙述和新问题做同时改写。基线为上一轮最终模型evidence_round_03。主指标分别报告正确/拒答/错误数量，不把拒答计为错误回答。完整保存预测记录和门槛。

负例：屏蔽正确支持480题、清空载荷480题、两套新历史中所有未观察事件各384题。屏蔽是检索排除ID，初次与重试都排除，不声称物理删除。推理不传目标ID或标签，排除只用于负例压力测试。未观察问题、训练/验证数据不混用。

训练结束后不按新测试挑参数。保留旧回归集再测以审计45/13的去向，同时报告所有新测试结果。若失败，如实报告，不改门槛或静默换测试种子。组合修改不能单独归因；可用固定组件消融辅助解释。

## 第一阶段失败后公开追加的第二阶段

第一阶段typed_round_01在旧集45拒答/13错变为35拒答/0错。新第一套同时改写99拒答/126错变为77拒答/10错；第二套11拒答/21错变为7拒答/0错。但屏蔽支持的480题出现2次错误作答，这两个问题在支持存在时也选错了事件。新第一套10次错误中另外8次仍为情绪→原因混淆。第一阶段结果完整保留，90381/90382和句式0/1从此是开发集，不再声称独立留出。

第二阶段在第一阶段checkpoint上追加固定3000步、batch32，不使用这两套测试事实训练。新增问题语义地址头，直接从独立问题编码器预测项目/次数，替代只从压缩检索向量解码查询地址。证据分数上限为问题与事件的项目概率分布一致度乘以次数分布一致度；验证器不能把不确定或不一致的地址放大到0.99以上。问题头额外用train地址监督，增加情绪/原因最小对比的组合问句。写入器和检索编码器继续冻结；原双门槛与重试预算不变。

独立最终复测改用提前固定的新种子90391/90392和新完整句式2/3，未用于任何训练/校准。第一套仍做四条件，第二套同时改写；负例规模保持480屏蔽、480清零、768实际未观察问题。第二阶段测试前完成全部训练和验证，禁止根据最终复测再挑参数。结果报告必须披露第一阶段的2次无支持误答以及原始模板的拒答退化。
