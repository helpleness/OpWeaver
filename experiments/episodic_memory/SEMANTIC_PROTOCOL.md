# 语义读取与拒答实验：训练前方案

基于已训练的冻结 Qwen2.5-1.5B-Instruct。保留旧模型与数据库；新增候选运行目录，写入器变化后重建库。测试前固定数据清单与句式，训练/校准/测试seed为9201/9202/9203。

训练使用720组事件、1440个叙述视图、5040个问题，其中240组事件包含缺失字段，涵盖乱序事实、排除干扰字段的提问、无地址、超范围、复合问题和是非确认请求。六种字段各六类问法、六种答案表达。重点扩展语言结构和负例类型，而非简单增加重复句数量。校准120题、最终测试240题，分15类；事件、owner及句式家族分开。每个条件含六字段轮转；小样本分布不完全均衡，报告逐类分母。

候选结构：可训练问题字段头（六字段+不支持）、含“缺失”类的潜变量事实头、按预测字段选择连续记忆槽的生成器。事实头负责支持度和一致性验证，不把解码出的事实文字喂给语言模型。生成器仍从磁盘潜变量生成答案；接受文本限定为声明过的六种表达语法，避免把包含关键词但是否定/编造的句子放行。这是有限词表研究原型，不是开放域事实核验。

训练分两阶段：扩展监督训练写入器、问题字段头、地址头和缺失事实头；再冻结它们训练连续读取投影。词嵌入对齐维持接口可读性，语言模型主干始终冻结。先使用固定训练步数，任何追加训练或结构调整须注明发生在查看哪一部分结果之后。

地址证据仍须严格>0.99。新的语义支持分数为问题字段概率与对应潜变量事实类别概率的较小值，须严格大于校准阈值；候选阈值仅允许从0.8、0.9、0.95、0.99、0.995、0.999、1.0中选。只能用校准集选择使错误放行为0的最低阈值，不能根据测试降低。数值相同不代表与旧词概率度量具有相同风险；同时报告最终错误、拒答和覆盖率。

同地址多条记忆在目标字段存在冲突时拒答；完全重复的同事实记录允许回答。检查只访问owner隔离的地址与有限载荷，不读事件原文或测试真值。无记忆、错地址、错owner、目标字段缺失、无锚点、问题超范围、问题多字段、是非请求、矛盾记忆、不存在事件、损坏载荷分别统计拒答；复合和是非题是原型明确不支持的能力，不能称这些问题本身不可回答。

同地址单条反事实记忆应跟随注入内容，不可能仅靠记忆模块判定用户存入的内容是否现实为真。保留这种条件与冲突条件的区别。

## 开发阶段修订（最终测试尚未运行）

初版600步读取训练后，原120题校准集上32个有支持问题仅12个通过，主要原因是自然语言生成超出有限核验语法。该集现改作开发集，原结果保留在`semantic_memory_01/calibration`，不再用来报告独立校准风险。

修订版把用户问法只交给学习的字段/地址模块，读取器使用所预测字段的统一读取指令，仍不提供事实答案。训练问题扩展至6480条，加入排除无关字段与请求多个字段的组合对照，以及年龄、时间段、他人感受等近邻超范围负例。沿用720组事件和原写入器，追加1500步问题模块训练与400步读取投影训练。新校准集seed9205使用另一套问法；最终240题测试文件逐字保持原样，训练和修订时未运行测试推理。

第二次开发修订：seed9205集仅10/32个支持问题通过，主要原因变为原始问题隐藏向量上的小池化分类器过度预测“不支持”。此集也降级为开发集，结果保留。第三版冻结已有写入器和读取投影，给冻结Qwen输入明确的七类问题定义，提取回答起点的隐藏向量，训练新的线性字段头1000步；类别权重抵消“不支持”训练样本更多的影响。查询特征预算由原始192-token路径改为该上下文路径最多320-token，地址路径仍使用原始问题。另建seed9207及新句式的120题最终校准集；原240题最终测试继续逐字保留。此次不增加读取器训练步数、不根据最终测试调参。

对照：旧1.5B与候选使用完全相同最终测试记录与问题。主指标为有支持条件的正确/错答/拒答、各无支持条件的错误放行、字段分类/缺失识别/寻址诊断。额外运行上一轮60个新问法作为已暴露回归集；不能当作本轮盲测。普通聊天路径前后对照，独立重启磁盘复现。任何未达到改善或风险要求的候选不替换原默认入口。
