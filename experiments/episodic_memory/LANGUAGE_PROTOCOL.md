# 问题理解与记忆读取分离：预定方案

基线是typed_round_02。先在上一轮已暴露的失败集做三种独立测量：只输入问题做六字段分类；给真实字段但仍使用正常检索/证据门槛；给真实字段和真实事件做记忆槽探针。后两者仅为带标签的诊断，不是部署路径。干预问题的背景从句和定位锚点，以检验对无关内容/位置的依赖。

主修改只替换问题字段理解，不更新写入器、数据库、检索器、地址判断或槽解码器。独立中文编码器UER chinese_roberta_L-4_H-256，4层、hidden256；附6分类头。对照随机初始化同架构，避免将模型变大误认为预训练的收益。已有原型没有通用语言预训练，也没有自回归语言生成目标。

2×2对照：随机/预训练初始化 × 窄分布/组合数据。四组同结构、同1200步、batch24（双视图48句）、同学习率1e-4和种子62。分类CE加0.1 JS一致性损失。每组12000训练问题、1200验证问题；问题与同义正视图都纳入跨训练/验证去重，数据SHA256留档。最早的language_round_01是数据审计前试运行，发现正视图跨验证重复，作废且不用于测试；修复后完整重训language_round_02。

组合数据不是补旧失败句子：独立采样目标字段、背景、项目/次数、句子位置和指令范围；同背景对应六种不同字段的反事实组；相同字段在不同背景/锚点上保持一致。包含普通提问、排除另一个问题、引用先前问题后提出当前问题的结构。标签来自生成时的语法树，推理没有关键词规则或真实字段标签。验证只用于检查训练，不根据最终测试选模型或门槛。

训练结构族0–5，最终测试结构族6–9；最终目标问句实现也独立留出。仅共享语言词汇和任务定义，不共享完整句子。结构6/7测试背景从句与位置，8/9额外测试否定/引用作用范围。测试前固定事件种子90611/90612及问题种子，输出完整原始文本与预测，检查与所有训练/验证正视图零交集。

最终测量：独立问题分类混淆矩阵和高置信错分；独立记忆解码；新事件的端到端四条件（原始/只换问题/只换事件/都换），第二套新事件的都换；屏蔽支持、清空载荷、实际未存事件压力测试。保持证据>0.99、最终值>0.8及一次重试，新的意图概率直接参与原有字段边缘化。不得按字段强行归一化为one-hot来提高作答率。

主要模型预先固定为pretrained_compositional，其余均为对照，不根据最终测试改选。原记忆模型有限词表保持不变，必须记录新问题经过旧地址编码器时的未知符号，不能把地址编码问题误算成字段理解。原型仍只能返回六个字段的有限答案，预训练前端不是生成聊天模型，也没有把记忆换成聊天原文检索。

资料：UER模型卡 https://huggingface.co/uer/chinese_roberta_L-4_H-256 ；Chinchilla论文 https://arxiv.org/abs/2203.15556 ；FineWeb论文 https://arxiv.org/abs/2406.17557 。预训练权重来源与SHA256记录在本地实验中。预训练语料可能包含通用句法，不能宣称测试句式对预训练阶段绝对未见。
