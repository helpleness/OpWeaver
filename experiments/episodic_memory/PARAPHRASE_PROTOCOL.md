# 改写泛化实验方案（训练前固定）

2026-10-26。先完成旧模型模板2的配对诊断，再据此确定本方案；模板2结果属于已知诊断集，不作为全新泛化证据。

## 配对测试

每个模型使用相同test事实、owner、事件ID、600个问题样本（种子901），仅改变语言表现：原句、只换问题、只换事件叙述、两者都换。使用同一份原始事实重建改写事件数据库；不混用不同历史。每个条件480个已存问题、120个未知问题。

模板2用于诊断和复测；新的模板3由`paraphrases.py`的`heldout_*`定义，仅在最终测试使用，训练、验证选checkpoint和调参均不用。它是受控语言重组测试，不是任意自然语言基准。

诊断额外进行内部表示干预：保留改写问题的地址，只替换为原问法的读取表示；反向只替换地址也测试。这些只用于分析，不能当真实推理成绩。

## 三个条件

1. `pilot_03`：已保存的旧模型，原句训练。
2. `paraphrase_aug_v2`：架构不变，增加随机重排的事件子句、同义标记和提问包装；无新模型损失。
3. `paraphrase_structured`：相同增强数据，增加预测式六类问题意图瓶颈（softmax加权意图嵌入，推理不提供任务真值）、意图分类损失、多视图内容槽与地址余弦一致性损失。

两组新实验都从零训练，seed42；192×32条训练事实，batch8，第一阶段5000步，第二阶段500步。词表仍是184个符号；事实生成器随机序列不变。增强按固定种子1127为事件生成6个额外视图、每类问题4个额外视图，每批随机抽取。模板2和3的完整句式不作为训练样本，所用词语可出现在训练的其他组合中。

原损失保持不变；第三组增加：0.5×当前视图意图CE + 0.5×第二视图意图CE + 0.2×三项平均余弦距离（内容槽、事件地址、问题地址）。只对当前批次正事件多编码一个视图。第二阶段冻结writer，保留意图CE，取消内容一致性训练。离散路由不反向传播。

用增强版验证集总损失选第一阶段checkpoint，第二阶段固定步数。旧模型验证条件不同，因此除独立增强和结构损失外，checkpoint选择分布也有变化。第三组增加了少量参数和计算量，不能当成完全相同计算预算的比较。仅一个随机种子，比较是初步证据。

## 预定报告

四条件已存事件准确率、Recall@8、未知问题错误作答率、oracle上限、清空内容消融；原/改写表示相似度及槽辅助解码准确率；最终跨进程持久化复核。不得只报告最高分或把未知问题的20%基础分当记忆成绩。保留全部失败和原句退化。

## 启动时修正

隔离测试发现随机组合可能拼出模板2完整问题。首次`paraphrase_aug`在约2000步被主动终止，未做最终评估，不进入比较。生成器现显式排除模板2/3完整问句；通过测试后从零重启为`paraphrase_aug_v2`。第三组尚未启动时即已修正。此修正不使用新测试集成绩。
