# 原始 Qwen 补充对照（运行前固定）

本轮补齐此前缺少的“未接记忆模块”的基线。使用与semantic_memory_03完全相同的官方Qwen2.5-1.5B-Instruct权重及revision，同一份semantic_suite_03/test.json的240个问题，贪心生成、40个新token上限。仅直接实例化官方语言模型，不加载任何记忆适配器、分类头或外部门控。全部原始输出直接保存；不对原始模型套用最低词概率门槛。

这是对已公开测试集的事后补充对照，不是新的盲测。本轮不训练、不调整现有记忆模型或阈值。

四组：

1. 原始聊天、没有经历：使用原普通聊天系统提示，问题保持原样。观察其面对未见私人经历的行为；不能将猜中当作记忆。
2. 同任务规则、没有经历：明确与新系统相同的六字段、单事件、缺失/矛盾时拒答等范围，但不提供任何事件文字。区分系统提示与记忆信息的作用。
3. 同任务规则、全部可用经历文字：提供该用户本题库内的完整文字（含干扰事件、重复或矛盾记录）。过滤其他用户；对清零载荷只保留记录不可用的提示，不泄漏对应事实。无检索、无真值选取；这是短上下文能力对照，不是部署中的记忆实现。
4. 同任务规则、指定目标事件文字：仅在64道有支持题上，实验者直接提供正确事件文字。明确标为oracle，只用于判断语言模型本身能否读懂；不计为系统成功率。

第2–4组共用系统提示，包含任务范围与统一拒答语，但不提供目标字段标签、答案或期望结果。上下文构造只使用事件文本和owner/可用性元数据，不读取values或expected。完整文字条件与潜变量条件的信息表示不同，不能当成完全单因素消融。

主评分保留原先“目标字段唯一值匹配/标准拒答/未匹配”以供复核；另对未匹配、同义表达、澄清请求和其他措辞的拒答进行文本核查。未匹配不能全部称为事实错误。报告截断数，不将未正常结束的回答当作完整正确答案。原始聊天组没有同任务格式要求，不能用标准拒答字符串匹配率评价其通用聊天能力。

额外用原来的8个普通聊天问题直接询问原始Qwen，与新记忆系统显式chat旁路的保存结果比较。这只检验显式普通聊天路径，不证明开启记忆时的自由聊天没有退化。

执行方式说明：首个顺序运行在GPU低频状态下过慢，保留部分输出并中止；正式完整运行改为batch=8、左侧padding，问题、提示、贪心解码与输出长度不变。BF16批量计算可能有微小数值差异，不作逐token等价或速度比较；普通聊天8题仍单条运行。部分运行不参与最终评分，也不用于挑选答案。
